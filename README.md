# Shooting Academy Website

Modern React website for a shooting academy, built with Vite.

## Tech Stack

- React
- Vite
- CSS

## Run Locally

```bash
npm install
npm run dev
```

The dev server starts at `http://localhost:5173`.

## Build

```bash
npm run build
```

## Current Sections

- Hero with academy value proposition and CTA
- Training program cards
- Weekly schedule board
- Coaching team highlights
- Contact/registration footer CTA
